# SafeChat AI

Local prototype for analyzing exported chat logs and images for safety risks.

## Prerequisites
- Python 3.10
- Node.js (16+)
- Optional: Tesseract-OCR (for image OCR) — add to PATH on Windows.
- Optional: set `HF_TOKEN` environment variable for faster Hugging Face downloads.

## Backend (Python / FastAPI)

1. Create a virtual environment and install dependencies:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r backend/requirements.txt
```

2. Run the API server (development):

```powershell
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

Endpoints:
- `POST /api/analyze/upload` — upload a WhatsApp `.txt` export (multipart form `file`).
- `GET /api/analyze/report/{chat_id}` — fetch analysis report and messages.
- `POST /api/image/upload` — upload image for OCR + analysis.

Notes:
- On first run the AI models (Detoxify, HF emotion model) will download and may take several minutes.
- If you have a local custom model, place it in `best_model/` (optional). The engine will skip if missing.
- If using OCR, install Tesseract and set `pytesseract.pytesseract.tesseract_cmd` if necessary.

## Frontend (React + Vite)

1. Install and run the frontend:

```powershell
cd frontend
npm install
npm run dev -- --host 127.0.0.1
```

2. Open the app in the browser (default Vite port): `http://127.0.0.1:5173`.
